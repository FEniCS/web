# Fonts

`inter-latin.woff2` and `inter-latin-ext.woff2` are the Inter variable font,
subset to the Latin and Latin Extended ranges, as served by Google Fonts
(Inter v20). They are self-hosted so that the website makes no third-party
request when someone opens a page.

Inter is by Rasmus Andersson and is used under the SIL Open Font License,
version 1.1; the licence is in `LICENSE-Inter.txt`. See
<https://github.com/rsms/inter>.

The `@font-face` rules that load these files are in `assets/css/custom.css`.
