{{- /* The banner at the top of a page: the background image, with the page title and subtitle set over it. Called with a dict: page The page the banner belongs to, read for the settings below. title The title, set over the image. subtitle An optional second line, set under the title. May contain HTML, so
can be used to break it over several lines. Hextra renders its own

immediately below this partial. The title is drawn here instead, and custom.css hides that

and the spacing around it, so the title is shown once. The theme itself is not touched. Front matter of the page: image Banner image, e.g. /assets/img/headers/oriel.jpg. Defaults to params.defaultHeaderImage in hugo.yaml. imageFit How the image is sized: cover -- fill the banner, cropping as needed (photographs) auto -- scale to the height of the banner (logos, maps) tile -- repeat at its natural size (the default image) headerLogo Set to true to show the FEniCS logo above the title. */ -}} {{- $page := .page -}} {{- $image := $page.Params.image | default site.Params.defaultHeaderImage -}} {{- $fit := $page.Params.imageFit | default (cond (eq $image site.Params.defaultHeaderImage) "tile" "auto") -}} {{- /* The image is drawn by a pseudo-element, so that the front page can soften it without softening the logo and title on top of it. */ -}} {{- $style := printf "--fenics-banner-image:url(%s)" ($image | relURL) -}} {{- if eq $fit "cover" -}} {{- $style = printf "%s;--fenics-banner-size:cover" $style -}} {{- else if eq $fit "tile" -}} {{- $style = printf "%s;--fenics-banner-repeat:repeat" $style -}} {{- else -}} {{- $style = printf "%s;--fenics-banner-size:auto 400px" $style -}} {{- end -}}
